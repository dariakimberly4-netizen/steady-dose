# Steady Dose

A Parkinson’s-friendly medication and symptom tracker created for Kimberly Daria.

## Features

- One-tap dose logging: taken, late, or skipped
- ON, OFF, dyskinesia, and freezing check-ins
- Daily medication schedule and adherence summary
- Caregiver view and printable doctor report
- Large tremor-friendly controls
- Works offline after loading; data stays on the device
- Phone, tablet, and computer responsive design

## Use

Open `index.html`, or enable GitHub Pages from **Settings → Pages → Deploy from branch → main**.

> This tracker does not provide medical advice or medication recommendations.
